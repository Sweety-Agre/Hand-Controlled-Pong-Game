# Hand-Controlled-Pong-Game
🏓 Hand Controlled Pong Game

A simple and interactive Pong game controlled using hand gestures through a webcam.

Instead of using a keyboard or mouse, the player can control the paddle by moving their hand in front of the camera. The project uses computer vision and hand-tracking technology to detect hand movements in real time.

✨ Features

- 🎮 Hand gesture-based paddle control
- 📷 Real-time webcam hand tracking
- 🖐️ Uses hand movement to move the paddle
- ⚡ Real-time gameplay
- 🏓 Classic Pong game concept
- 💻 Easy to run using Python

🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- cvzone
- NumPy
- Pygame

⚙️ Installation

1. Clone the repository

git clone https://github.com/Sweety-Agre/Hand-Controlled-Pong-Game.git

2. Open the project folder

cd Hand-Controlled-Pong-Game

3. Install the required libraries

pip install opencv-python mediapipe cvzone numpy pygame

▶️ How to Run

Open the project in VS Code or PyCharm and run:

python main.py

Make sure your webcam is connected and accessible.

🎯 How to Play

1. Start the game.
2. Allow webcam access if requested.
3. Place your hand in front of the camera.
4. Move your hand up and down to control the paddle.
5. Try to hit the ball and score points.

🎓 Project Purpose

This project demonstrates how computer vision, hand tracking, and Python game development can be combined to create an interactive gaming experience without traditional keyboard controls.
